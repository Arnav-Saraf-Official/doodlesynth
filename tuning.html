scale

Ratios attach to the base note: with a tuning and a base note selected, every note resolves as base × ratio, so the whole set stays in proportion. Static JI keeps the anchor on the master root; Dynamic JI lets it follow the root or a manual chord root, so the same ratios re-fit the chord as the harmony moves (Alosynth-style re-anchoring). Absolute-Hz curves are never rewritten by these settings. Only points drawn on a scale-relative track re-resolve their pitch when the root, scale or anchor changes.
